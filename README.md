# e-commerce-project-kts

> [!WARNING]
> предполагается что все действия будут происходить из корня проекта

## Клонирование репозитория

```cmd
git clone https://github.com/nais2008/e-commerce-project-kts
cd ./e-commerce-project-kts
```

## Заполнение переменных среды

### Создание файла

```cmd
touch .env
```

### Заполняем

```env
VITE_STRAPI_TOKEN=your_strapi_token
```

## Установка зависимостей

```cmd
npm install
```

## Запуск

```cmd
npm run dev
```
